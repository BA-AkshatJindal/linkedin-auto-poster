## ❓ 6. Investor Q&A & Risk Mitigation

### Q1: Is this compliant with LinkedIn's API Policies?
> **Answer:** Absolutely. LinkedAutomate operates 100% via official LinkedIn REST API endpoints (`/rest/posts`, `/rest/documents`, `/rest/images`, `/v2/socialActions`). We do **not** use risky browser automation, headless Puppeteer, or DOM scraping that triggers account flags.

### Q2: How do you prevent repetitive AI content?
> **Answer:** The engine includes a **15-post persistent memory state** (`history_posts.json`). Every generation cycle checks historical topics, hooks, and formats, dynamically injecting anti-duplication constraints into the AI prompt.

### Q3: What happens if Gemini API hits rate limits or downtime?
> **Answer:** LinkedAutomate features an automated **Multi-Model Redundancy Fallback Chain**: `Gemini 2.5-Flash` ➔ `Gemini 2.0-Flash` ➔ `Gemini 1.5-Flash` ➔ `Pollinations FLUX fallback`. Execution success rate is 99.9%.
